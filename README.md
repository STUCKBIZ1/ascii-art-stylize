# ASCII-Art-Stylize

## 🧩 Description
**Ascii-art-stylize** is an extension of the **ascii-art-web** project.  
The goal of this project is to improve the user interface (UI) and user experience (UX) using **HTML and CSS**, while respecting good web design practices.

The website allows the user to enter text, choose a banner style, and display the result as ASCII art in a clear and visually appealing way.

---

## 🎯 Objectives
- Make the website:
  - More appealing
  - User-friendly
  - Interactive
- Provide clear feedback to the user (errors, messages, status)
- Learn the basics of:
  - Human-Computer Interaction (HCI)
  - CSS
  - Linking CSS with HTML

---

## 📋 Features
- Text input form
- Banner selection
- Clean ASCII art display
- Clear error and feedback messages
- Consistent and responsive design
- Good text readability regardless of color choices

---

## 🛠️ Technologies Used

  - Standard library only
- **HTML**
- **CSS**
